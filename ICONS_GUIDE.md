# GOD-TIER ICON PACK // MASTERPIECE.OS

## Описание
В репозитории `public/` находятся анимированные SVG-иконки с встроенным CSS-движком. Каждая иконка спроектирована как визуальный триггер для закрытия конкретной боли клиента.

## Использование
Иконки можно использовать через обычный тег `<img>` или `next/image`, анимация работает в любом браузере:

```html
<img src="/cyber-mascot.svg" alt="Cyber Mascot" className="w-12 h-12" />
```
